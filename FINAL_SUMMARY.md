## 🚀 How to Run

### **Development**

**Backend:**
```cmd
cd backend
.venv\Scripts\activate
python manage.py runserver
```
→ `http://localhost:8000`

**Frontend:**
```cmd
cd frontend
npm run dev
```
→ `http://localhost:5174`

### **Production Deployment**

1. **Set Environment Variables** (see FINALIZATION_COMPLETE.md)
2. **Change DEBUG=False**
3. **Set up PostgreSQL**
4. **Configure HTTPS**
5. **Set ALLOWED_HOSTS**
6. **Run migrations**
7. **Collect static files**
8. **Deploy!**
